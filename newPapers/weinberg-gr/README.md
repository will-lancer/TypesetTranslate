# Weinberg GR — modernized notation edition

The verified delivery PDF for Steven Weinberg's *Gravitation and Cosmology*
will be written here as `weinberg-gr-modernized.pdf`.

The reproducible LaTeX source, transcription manifest, notation policy, and QA
tools live in `../build-directories/weinberg_gr`. The original 681-page scan is
kept separately at `../../origPapers/weinberg_gr.pdf`.

The delivery PDF is created only by a successful strict run of:

```sh
../build-directories/weinberg_gr/build_and_verify.sh
```
