\subsection{What is quantum field theory?}
\label{sec:253a-what-is-qft}

% YIN-SOURCE: id=YIN253A-C01-V-T000016; notes=253a:1; pdf=6; video=OY_napMPywE:00:05:02.580-00:05:13.500; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000016
What is quantum field theory? This question is very easy to answer, at least
roughly: it is basically quantum mechanics with relativistic locality.
% YIN-SPEECH-END YIN-OY-T000016
% YIN-SOURCE: id=YIN253A-C01-V-T000017; notes=253a:1; pdf=6; video=OY_napMPywE:00:05:13.500-00:05:33.360; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000017
Of course, we have not yet explained what relativistic locality means.
% YIN-SPEECH-END YIN-OY-T000017

% YIN-SOURCE: id=YIN253A-C01-V-T000018; notes=253a:1; pdf=6; video=OY_napMPywE:00:05:33.360-00:05:57.419; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000018
In fact, this is a confusing question even for the vast majority of physicists,
because the name quantum field theory is used for two conceptually distinct
things.
% YIN-SPEECH-END YIN-OY-T000018
% YIN-SOURCE: id=YIN253A-C01-V-T000019; notes=253a:1; pdf=6; video=OY_napMPywE:00:05:57.419-00:06:29.100; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000019
I want to discuss both in this course. One is a local, or ultraviolet-complete,
QFT; the other is an effective field theory.
% YIN-SPEECH-END YIN-OY-T000019
% YIN-SOURCE: id=YIN253A-C01-V-T000020; notes=253a:1; pdf=6; video=OY_napMPywE:00:06:29.100-00:06:42.900; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000020
It is a little easier to begin by saying what a local QFT means.
% YIN-SPEECH-END YIN-OY-T000020

% YIN-SOURCE: id=YIN253A-C01-V-T000021; notes=253a:1; pdf=6; video=OY_napMPywE:00:06:42.900-00:07:04.280; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000021
First of all, a local QFT is equipped with Poincaré symmetry, which consists of
spacetime translations together with Lorentz transformations.
% YIN-SPEECH-END YIN-OY-T000021
% YIN-SOURCE: id=YIN253A-C01-V-T000022; notes=253a:1; pdf=6; video=OY_napMPywE:00:07:04.280-00:07:27.300; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000022
This kind of fundamental theory, first of all, is a quantum-mechanical system.
Some folks might have the slight misconception that quantum field theory, going
beyond quantum mechanics, is a generalization of quantum mechanics: no, quantum
field theory is not a generalization of quantum mechanics. Quantum field theory
is a specialization of quantum mechanics.
% YIN-SPEECH-END YIN-OY-T000022
% YIN-SOURCE: id=YIN253A-C01-V-T000023; notes=253a:1; pdf=6; video=OY_napMPywE:00:07:27.300-00:07:51.319; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000023
We will allow this quantum-mechanical system to have infinitely many degrees of
freedom.
% YIN-SPEECH-END YIN-OY-T000023

% YIN-SOURCE: id=YIN253A-C01-V-T000024; notes=253a:1; pdf=6; video=OY_napMPywE:00:07:51.319-00:08:04.800; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000024
One requirement on top of the quantum mechanics you learn as an undergraduate
is Poincaré symmetry.
% YIN-SPEECH-END YIN-OY-T000024
% YIN-SOURCE: id=YIN253A-C01-V-T000025; notes=253a:1; pdf=6; video=OY_napMPywE:00:08:04.800-00:08:22.560; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000025
As in any quantum-mechanical system, a symmetry is represented by a unitary
operator on the Hilbert space, and operators transform by conjugation.
% YIN-SPEECH-END YIN-OY-T000025
% YIN-SOURCE: id=YIN253A-C01-V-T000026; notes=253a:1; pdf=6; video=OY_napMPywE:00:08:22.560-00:08:31.620; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000026
For now, I am giving a very broad overview. All of these words will be put in
the form of precise equations below.
% YIN-SPEECH-END YIN-OY-T000026

% YIN-SOURCE: id=YIN253A-C01-V-T000028; notes=253a:1; pdf=6; video=OY_napMPywE:00:08:51.120-00:09:09.839; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000028
But that is not all. A local QFT must also contain local operators, often called
field operators.
% YIN-SPEECH-END YIN-OY-T000028
% YIN-SOURCE: id=YIN253A-C01-V-T000029; notes=253a:1; pdf=6; video=OY_napMPywE:00:09:09.839-00:09:19.500; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000029
These field operators obey Poincaré covariance and microcausality.
% YIN-SPEECH-END YIN-OY-T000029
% YIN-SOURCE: id=YIN253A-C01-V-T000030; notes=253a:1; pdf=6; video=OY_napMPywE:00:09:19.500-00:09:38.279; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000030
Basically, this is a precise quantum-mechanical statement that captures the idea
that signals cannot propagate faster than the speed of light in a relativistic
theory.
% YIN-SPEECH-END YIN-OY-T000030

% YIN-SOURCE: id=YIN253A-C01-V-T000031; notes=253a:1; pdf=6; video=OY_napMPywE:00:09:38.279-00:09:47.519; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000031
What, then, is an effective field theory?
% YIN-SPEECH-END YIN-OY-T000031
% YIN-SOURCE: id=YIN253A-C01-V-T000032; notes=253a:1; pdf=6; video=OY_napMPywE:00:09:47.519-00:10:02.160; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000032
It is not really possible to explain effective field theory in detail without
first setting up some technical tools. For now, a few general facts will
suffice.
% YIN-SPEECH-END YIN-OY-T000032

% YIN-SOURCE: id=YIN253A-C01-V-T000033; notes=253a:1; pdf=6; video=OY_napMPywE:00:10:02.160-00:10:10.980; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000033
% Brief classroom aside omitted.
% YIN-SPEECH-END YIN-OY-T000033
% YIN-SOURCE: id=YIN253A-C01-V-T000034; notes=253a:1; pdf=6; video=OY_napMPywE:00:10:10.980-00:10:25.740; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000034
An effective field theory is typically defined only perturbatively in some
coupling.
% YIN-SPEECH-END YIN-OY-T000034
% YIN-SOURCE: id=YIN253A-C01-V-T000035; notes=253a:1; pdf=6; video=OY_napMPywE:00:10:25.740-00:10:47.700; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000035
So, by contrast, there are plenty of examples of quantum field theories that are
completely well-defined at strong coupling. These effective field theories are
typically only defined as a formal perturbative series in the coupling constant,
and it may not have a well-defined limit. In particular, it may or may not
converge.
% YIN-SPEECH-END YIN-OY-T000035

% YIN-SOURCE: id=YIN253A-C01-V-T000036; notes=253a:1; pdf=6; video=OY_napMPywE:00:10:47.700-00:11:01.320; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000036
Its usual formulation is a path integral, namely a functional integral over a
space of fields.
% YIN-SPEECH-END YIN-OY-T000036
% YIN-SOURCE: id=YIN253A-C01-V-T000037; notes=253a:1; pdf=6; video=OY_napMPywE:00:11:01.320-00:11:18.300; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000037
A path integral can also define a local fundamental theory, provided that the
definition makes sense nonperturbatively.
% YIN-SPEECH-END YIN-OY-T000037
% YIN-SOURCE: id=YIN253A-C01-V-T000038; notes=253a:1; pdf=6; video=OY_napMPywE:00:11:18.300-00:11:38.880; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000038
By design, an effective field theory captures long-distance or low-energy
observables, with no claim beyond its regime of validity.
% YIN-SPEECH-END YIN-OY-T000038

% YIN-SOURCE: id=YIN253A-C01-V-T000040; notes=253a:1; pdf=6; video=OY_napMPywE:00:11:56.160-00:12:14.160; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000040
% YIN-FORMULA-ID YIN253A-C01-F-000040
To make locality more concrete, let me say very roughly that we have a field
operator $\hat\phi(x)$ associated with a spacetime point $x$.
% YIN-SPEECH-END YIN-OY-T000040
% YIN-SOURCE: id=YIN253A-C01-V-T000041; notes=253a:1; pdf=6; video=OY_napMPywE:00:12:14.160-00:12:22.380; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000041
% YIN-FORMULA-ID YIN253A-C01-F-000041
By itself, saying that an operator is associated with a point is not very
meaningful, since I can parametrize a family of operators however I want.
% YIN-SPEECH-END YIN-OY-T000041
% YIN-SOURCE: id=YIN253A-C01-V-T000042; notes=253a:1; pdf=6; video=OY_napMPywE:00:12:22.380-00:12:32.339; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000042
There are two key criteria that give the spacetime label its meaning. First,
% YIN-SPEECH-END YIN-OY-T000042
% YIN-SOURCE: id=YIN253A-C01-V-T000043; notes=253a:1; pdf=6; video=OY_napMPywE:00:12:32.339-00:12:46.500; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000043
% YIN-FORMULA-ID YIN253A-C01-F-000043
under a Poincaré transformation that sends one spacetime point to another, the
corresponding unitary operator sends $\hat\phi$ to the field operator at the
transformed point.
% YIN-SPEECH-END YIN-OY-T000043
% YIN-SOURCE: id=YIN253A-C01-V-T000044; notes=253a:1; pdf=6; video=OY_napMPywE:00:12:46.500-00:13:17.820; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000044
% YIN-FORMULA-ID YIN253A-C01-F-000044
Second, the operators obey microcausality: field operators at
spacelike-separated, and hence causally disconnected, points commute. Poincaré
covariance and microcausality are the essential criteria for locality. This
concept is rather alien if you only know undergraduate quantum mechanics, but it
will be central to our study of QFT.
% YIN-SPEECH-END YIN-OY-T000044

\subsection{Plan of Physics 253a}
\label{sec:253a-plan}

% YIN-SOURCE: id=YIN253A-C01-V-T000064; notes=253a:2; pdf=7; video=OY_napMPywE:00:19:14.400-00:19:29.640; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000064
Let me describe the plan of the course. It has three parts.
% YIN-SPEECH-END YIN-OY-T000064

% YIN-SOURCE: id=YIN253A-C01-V-T000065; notes=253a:2; pdf=7; video=OY_napMPywE:00:19:29.640-00:19:45.360; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000065
We begin with good old nonrelativistic quantum mechanics with a few degrees of
freedom, but study it in
% YIN-SPEECH-END YIN-OY-T000065
% YIN-SOURCE: id=YIN253A-C01-V-T000066; notes=253a:2; pdf=7; video=OY_napMPywE:00:19:45.360-00:20:05.039; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000066
a language that may be unfamiliar from an undergraduate course but is standard
in QFT. Rather than beginning with the Hamiltonian, we use
% YIN-SPEECH-END YIN-OY-T000066
% YIN-SOURCE: id=YIN253A-C01-V-T000067; notes=253a:2; pdf=7; video=OY_napMPywE:00:20:05.039-00:20:16.080; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000067
the Lagrangian formulation of quantum mechanics.
% YIN-SPEECH-END YIN-OY-T000067

% YIN-SOURCE: id=YIN253A-C01-V-T000068; notes=253a:2; pdf=7; video=OY_napMPywE:00:20:16.080-00:20:33.360; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000068
As you probably know, in classical mechanics the Lagrangian and Hamiltonian
formulations are more or less equivalent. One may
% YIN-SPEECH-END YIN-OY-T000068
% YIN-SOURCE: id=YIN253A-C01-V-T000069; notes=253a:2; pdf=7; video=OY_napMPywE:00:20:33.360-00:20:47.880; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000069
define a mechanical system by a Lagrangian, or action, and derive the
Euler--Lagrange equations by extremizing the action.
% YIN-SPEECH-END YIN-OY-T000069
% YIN-SOURCE: id=YIN253A-C01-V-T000070; notes=253a:2; pdf=7; video=OY_napMPywE:00:20:47.880-00:21:04.679; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000070
Alternatively, a classical state is a point in phase space, specified by
coordinates and momenta. A Legendre transformation produces the Hamiltonian and
its equivalent equations of motion.
% YIN-SPEECH-END YIN-OY-T000070

% YIN-SOURCE: id=YIN253A-C01-V-T000071; notes=253a:2; pdf=7; video=OY_napMPywE:00:21:04.679-00:21:13.740; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000071
When you first learn classical mechanics, you are probably not very impressed,
because these formulations look like trivial rewritings of one another. Why
bother?
% YIN-SPEECH-END YIN-OY-T000071
% YIN-SOURCE: id=YIN253A-C01-V-T000072; notes=253a:2; pdf=7; video=OY_napMPywE:00:21:13.740-00:21:39.480; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000072
In quantum mechanics, as you probably noticed, the Hamiltonian is promoted from
a classical function on phase space to an operator on the Hilbert space. Its
eigenvalues give the energy spectrum, making it an essential object
% YIN-SPEECH-END YIN-OY-T000072
% YIN-SOURCE: id=YIN253A-C01-V-T000073; notes=253a:2; pdf=7; video=OY_napMPywE:00:21:39.480-00:21:57.120; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000073
in the theory. The Lagrangian has no comparably direct operator interpretation,
and it is not even clear by itself what a quantum Lagrangian should mean.
% YIN-SPEECH-END YIN-OY-T000073

% YIN-SOURCE: id=YIN253A-C01-V-T000074; notes=253a:2; pdf=7; video=OY_napMPywE:00:21:57.120-00:22:18.480; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000074
Formally, the only way I know to formulate quantum mechanics through a
Lagrangian is the path integral. We will develop it together with the concept of
regularization,
% YIN-SPEECH-END YIN-OY-T000074
% YIN-SOURCE: id=YIN253A-C01-V-T000075; notes=253a:2; pdf=7; video=OY_napMPywE:00:22:18.480-00:22:31.740; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000075
which is standard in QFT but already present in good old quantum mechanics with
only a few degrees of freedom. We then discuss
% YIN-SPEECH-END YIN-OY-T000075
% YIN-SOURCE: id=YIN253A-C01-V-T000076; notes=253a:2; pdf=7; video=OY_napMPywE:00:22:31.740-00:22:52.940; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000076
perturbation theory in the path-integral language and derive Feynman diagrams.
Feynman diagrams, in principle, have nothing to do with quantum field theory.
They have everything to do with the perturbative expansion of a path integral.
% YIN-SPEECH-END YIN-OY-T000076
% YIN-SOURCE: id=YIN253A-C01-V-T000077; notes=253a:2; pdf=7; video=OY_napMPywE:00:22:52.940-00:23:12.179; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000077
The same is true of renormalization and counterterms. In principle, they have
nothing to do with quantum field theory; they have everything to do with the
path-integral formulation of quantum mechanics.
% YIN-SPEECH-END YIN-OY-T000077

% YIN-SOURCE: id=YIN253A-C01-V-T000078; notes=253a:2; pdf=7; video=OY_napMPywE:00:23:12.179-00:23:27.900; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000078
After developing these tools, we turn to
% YIN-SPEECH-END YIN-OY-T000078
% YIN-SOURCE: id=YIN253A-C01-V-T000079; notes=253a:2; pdf=7; video=OY_napMPywE:00:23:27.900-00:23:45.419; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000079
relativistic particles and fields, beginning with scalar theories such as
$\phi^4$ theory.
% YIN-SPEECH-END YIN-OY-T000079
% YIN-SOURCE: id=YIN253A-C01-V-T000080; notes=253a:2; pdf=7; video=OY_napMPywE:00:23:45.419-00:24:04.980; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000080
We will introduce Green functions and the asymptotic states of a scattering
problem, which are more particle-physics-oriented concepts.
% YIN-SPEECH-END YIN-OY-T000080
% YIN-SOURCE: id=YIN253A-C01-V-T000081; notes=253a:2; pdf=7; video=OY_napMPywE:00:24:04.980-00:24:21.900; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000081
The scattering matrix, or S-matrix, is the central observable in a large class

% YIN-SPEECH-END YIN-OY-T000081
% YIN-SOURCE: id=YIN253A-C01-V-T000082; notes=253a:2; pdf=7; video=OY_napMPywE:00:24:21.900-00:24:31.799; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000082
This relation explains why Feynman diagrams compute scattering amplitudes.
% YIN-SPEECH-END YIN-OY-T000082

% YIN-SOURCE: id=YIN253A-C01-V-T000083; notes=253a:2; pdf=7; video=OY_napMPywE:00:24:31.799-00:25:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000083
The final part of the semester concerns particles
% YIN-SPEECH-END YIN-OY-T000083
% YIN-SOURCE: id=YIN253A-C01-V-T000084; notes=253a:2; pdf=7; video=OY_napMPywE:00:25:00.000-00:25:08.880; class=SPEECH_CLEAN

% YIN-SPEECH-END YIN-OY-T000091
\subsection{Relativistic particles without fields}
\label{sec:253a-relativistic-particles}

% YIN-SOURCE: id=YIN253A-C01-V-T000094; notes=253a:3; pdf=8; video=OY_napMPywE:00:27:19.620-00:27:34.100; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000094
Let us now give some motivation for fields.
% YIN-SPEECH-END YIN-OY-T000094

% YIN-SOURCE: id=YIN253A-C01-V-T000095; notes=253a:3; pdf=8; video=OY_napMPywE:00:27:34.100-00:28:09.799; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000095
The first question is: why do particle physicists need field theory? Why is it
not enough just to talk about particles? That is a very good question you should
ask yourself. More precisely, why is ordinary quantum mechanics insufficient
% YIN-SPEECH-END YIN-OY-T000095
% YIN-SOURCE: id=YIN253A-C01-V-T000096; notes=253a:3; pdf=8; video=OY_napMPywE:00:28:09.799-00:28:32.100; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000096
to describe particles with relativistic symmetry? It is not obvious why.
% YIN-SPEECH-END YIN-OY-T000096

% YIN-SOURCE: id=YIN253A-C01-V-T000097; notes=253a:3; pdf=8; video=OY_napMPywE:00:28:32.100-00:29:00.299; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000097
% YIN-FORMULA-ID YIN253A-C01-F-000097
Let us try. As in any quantum-mechanical system, we have a Hilbert space whose
vectors correspond to physical states. There will probably be a vacuum state;
let us call it $|\Omega\rangle$.
% YIN-SPEECH-END YIN-OY-T000097
% YIN-SOURCE: id=YIN253A-C01-V-T000098; notes=253a:3; pdf=8; video=OY_napMPywE:00:29:00.299-00:29:24.960; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000098
We will assume, and later see why this is reasonable, that the vacuum is
invariant under Poincaré symmetry. Otherwise a Poincaré transformation would
produce a different vacuum state, which sounds unreasonable.
% YIN-SPEECH-END YIN-OY-T000098
% YIN-SOURCE: id=YIN253A-C01-V-T000099; notes=253a:3; pdf=8; video=OY_napMPywE:00:29:24.960-00:29:42.779; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000099
% YIN-FORMULA-ID YIN253A-C01-F-000099
In particular, the Hamiltonian generates time translations, so invariance tells
us that the vacuum has zero energy:
% YIN-SPEECH-END YIN-OY-T000099
% YIN-SOURCE: id=YIN253A-C01-U024; notes=253a:3; pdf=8; video=OY_napMPywE:00:29:24.960-00:29:42.779; class=NOTES_EXACT
\begin{equation}
  H\ket{\Omega}=0.
  \label{eq:253a-vacuum-energy}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000100; notes=253a:3; pdf=8; video=OY_napMPywE:00:29:42.779-00:30:12.620; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000100
% YIN-FORMULA-ID YIN253A-C01-F-000100
On top of the vacuum, we can have particles. The one-particle sector admits a
basis labeled by spatial momentum, whose states we write as $|\mathbf p\rangle$.
% YIN-SPEECH-END YIN-OY-T000100
% YIN-SOURCE: id=YIN253A-C01-V-T000101; notes=253a:3; pdf=8; video=OY_napMPywE:00:30:12.620-00:30:38.399; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000101
% YIN-FORMULA-ID YIN253A-C01-F-000101
We write the Minkowski energy-momentum vector as $p^\mu$. Its time component,
the energy, is $p^0$, while its spatial part is $\mathbf p$. Unless stated
% YIN-SPEECH-END YIN-OY-T000101
% YIN-SOURCE: id=YIN253A-C01-V-T000102; notes=253a:3; pdf=8; video=OY_napMPywE:00:30:38.399-00:31:18.659; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000102
% YIN-FORMULA-ID YIN253A-C01-F-000102
otherwise, we will work in arbitrary spacetime dimension $D$. A particle
physicist might wonder why dimensions other than four matter. The Ising model
gives one answer: it describes an actual system in solid-state physics.
% YIN-SPEECH-END YIN-OY-T000102
% YIN-SOURCE: id=YIN253A-C01-V-T000103; notes=253a:3; pdf=8; video=OY_napMPywE:00:31:18.659-00:31:36.059; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000103
% YIN-FORMULA-ID YIN253A-C01-F-000103
Thus $\mu=0,\ldots,D-1$. For the moment, one can still picture $\mathbf p$ as a
three-dimensional vector.
% YIN-SPEECH-END YIN-OY-T000103
% YIN-SOURCE: id=YIN253A-C01-V-T000104; notes=253a:3; pdf=8; video=OY_napMPywE:00:31:36.059-00:32:00.299; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000104
A relativistic particle of definite mass obeys the relativistic dispersion
relation.
% YIN-SPEECH-END YIN-OY-T000104
% YIN-SOURCE: id=YIN253A-C01-V-T000105; notes=253a:3; pdf=8; video=OY_napMPywE:00:32:00.299-00:32:23.100; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000105
% YIN-FORMULA-ID YIN253A-C01-F-000105
If the vacuum energy is zero, the Hamiltonian acting on a one-particle state of
definite spatial momentum therefore gives the energy
$\sqrt{\mathbf p^{\,2}+m^2}$:
% YIN-SPEECH-END YIN-OY-T000105
% YIN-SOURCE: id=YIN253A-C01-U028; notes=253a:3; pdf=8; video=OY_napMPywE:00:31:36.059-00:32:23.100; class=NOTES_EXACT
\begin{equation}
  H\ket{\mathbf p}
  =\sqrt{\mathbf p^{\,2}+m^2}\,\ket{\mathbf p}.
  \label{eq:253a-one-particle-energy}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000107; notes=253a:3; pdf=8; video=OY_napMPywE:00:32:33.360-00:32:55.100; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000107
% YIN-FORMULA-ID YIN253A-C01-F-000107
So far, nothing, no big deal. We may also consider an $n$-particle state whose
particles have spatial momenta $\mathbf p_1,\mathbf p_2,\ldots,\mathbf p_n$.
% YIN-SPEECH-END YIN-OY-T000107
% YIN-SOURCE: id=YIN253A-C01-V-T000108; notes=253a:3; pdf=8; video=OY_napMPywE:00:32:55.100-00:33:21.559; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000108
For now, assume these are identical, non-interacting particles of the same mass.
The Hilbert space then contains states with arbitrary particle number, and the
Hamiltonian
% YIN-SPEECH-END YIN-OY-T000108
% YIN-SOURCE: id=YIN253A-C01-V-T000109; notes=253a:3; pdf=8; video=OY_napMPywE:00:33:21.559-00:33:52.940; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000109
% YIN-FORMULA-ID YIN253A-C01-F-000109
acts on $|\mathbf p_1,\ldots,\mathbf p_n\rangle$ with an energy equal to the sum
of the individual particle energies.
% YIN-SPEECH-END YIN-OY-T000109
% YIN-SOURCE: id=YIN253A-C01-U030; notes=253a:3; pdf=8; video=OY_napMPywE:00:33:21.559-00:33:52.940; class=EQUATION_NORMALIZED
\begin{equation}
  H\ket{\mathbf p_1,\ldots,\mathbf p_n}
  =\left(\sum_{i=1}^{n}\sqrt{\mathbf p_i^{\,2}+m^2}\right)
   \ket{\mathbf p_1,\ldots,\mathbf p_n}.
  \label{eq:253a-multiparticle-energy}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000110; notes=253a:3; pdf=8; video=OY_napMPywE:00:33:52.940-00:34:02.760; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000110
These are all the states, and we have specified how the Hamiltonian acts on each
of them. We are all set. We have solved this kind of system, and there is
nothing more to do.
% YIN-SPEECH-END YIN-OY-T000110
% YIN-SOURCE: id=YIN253A-C01-V-T000111; notes=253a:3; pdf=8; video=OY_napMPywE:00:34:02.760-00:34:25.500; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000111
How were these particles created? For this model, I do not care. I have declared
that the states exist. Scattering will answer a different question once
interactions are introduced. For the moment, this is our very simple system.
% YIN-SPEECH-END YIN-OY-T000111
% YIN-SOURCE: id=YIN253A-C01-V-T000113; notes=253a:3; pdf=8; video=OY_napMPywE:00:34:33.560-00:34:52.980; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000113
Linear superpositions of these states are allowed, as always. By
non-interacting, I mean that the energy of each basis state is the sum of the
particle energies, with no potential contribution from mutual interactions.
% YIN-SPEECH-END YIN-OY-T000113

% YIN-SOURCE: id=YIN253A-C01-V-T000117; notes=253a:3; pdf=8; video=OY_napMPywE:00:35:28.339-00:35:48.250; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000117
The model may be rather boring, but it shows that one can construct a
Lorentz-invariant quantum-mechanical system without ever talking about fields.
% YIN-SPEECH-END YIN-OY-T000117

% YIN-SOURCE: id=YIN253A-C01-V-T000119; notes=253a:3; pdf=8; video=OY_napMPywE:00:35:48.260-00:36:08.210; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000119
If you wish, creation and annihilation operators provide a convenient language
for these states. We can
% YIN-SPEECH-END YIN-OY-T000119
% YIN-SOURCE: id=YIN253A-C01-V-T000121; notes=253a:3; pdf=8; video=OY_napMPywE:00:36:09.480-00:36:25.569; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000121
introduce them as follows.
% YIN-SPEECH-END YIN-OY-T000121
% YIN-SOURCE: id=YIN253A-C01-V-T000123; notes=253a:3; pdf=8; video=OY_napMPywE:00:36:25.579-00:36:58.190; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000123
% YIN-FORMULA-ID YIN253A-C01-F-000123
We denote them by $a^\dagger_{\mathbf p}$ and $a_{\mathbf p}$. The spatial
momentum $\mathbf p$ is enough to specify the particle, since its energy is
fixed by the dispersion relation.
% YIN-SPEECH-END YIN-OY-T000123

% YIN-SOURCE: id=YIN253A-C01-N001; notes=253a:3-4; pdf=8-9; video=OY_napMPywE:00:35:48.260-00:37:00.480; class=EQUATION_NORMALIZED
We write the creation operator as $a_{\mathbf p}^{+}\equiv
a_{\mathbf p}^{\dagger}$.
% YIN-SOURCE: id=YIN253A-C01-V-T000125; notes=253a:3; pdf=8; video=OY_napMPywE:00:37:00.480-00:37:22.849; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000125
% YIN-FORMULA-ID YIN253A-C01-F-000125
The creation operator is defined by its action on states, in a more or less
obvious way. In particular, a one-particle state is obtained by acting with
$a^\dagger_{\mathbf p}$ on the vacuum.
% YIN-SPEECH-END YIN-OY-T000125
% YIN-SOURCE: id=YIN253A-C01-V-T000127; notes=253a:3,4; pdf=8,9; video=OY_napMPywE:00:37:22.859-00:37:38.510; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000127
% YIN-FORMULA-ID YIN253A-C01-F-000127
A two-particle state is obtained by acting with two creation operators, and so
forth:
% YIN-SPEECH-END YIN-OY-T000127
% YIN-SOURCE: id=YIN253A-C01-U035; notes=253a:3-4; pdf=8-9; video=OY_napMPywE:00:37:00.480-00:37:38.510; class=NOTES_EXACT
\begin{equation}
  \ket{\mathbf p}=a_{\mathbf p}^{+}\ket{\Omega},
  \qquad
  \ket{\mathbf p_1,\mathbf p_2}
  =a_{\mathbf p_1}^{+}a_{\mathbf p_2}^{+}\ket{\Omega},
  \qquad \text{etc.}
  \label{eq:253a-created-states}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000129; notes=253a:4; pdf=9; video=OY_napMPywE:00:37:38.520-00:37:56.810; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000129
% YIN-FORMULA-ID YIN253A-C01-F-000129
I have not yet specified the normalization of this basis of multiparticle
states. Let us do that now by specifying the commutation relations of $a$ and
$a^\dagger$.
% YIN-SPEECH-END YIN-OY-T000129
% YIN-SOURCE: id=YIN253A-C01-V-T000131; notes=253a:4; pdf=9; video=OY_napMPywE:00:38:00.260-00:38:19.849; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000131
% YIN-FORMULA-ID YIN253A-C01-F-000131
The creation operators commute with one another, as do the annihilation
operators.
% YIN-SPEECH-END YIN-OY-T000131
% YIN-SOURCE: id=YIN253A-C01-V-T000133; notes=253a:4; pdf=9; video=OY_napMPywE:00:38:22.140-00:38:51.890; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000133
% YIN-FORMULA-ID YIN253A-C01-F-000133
The mixed commutator is nonzero only when the particle momenta coincide. Let me
choose the normalization convention to be a delta function in $D-1$ spatial
dimensions.
% YIN-SPEECH-END YIN-OY-T000133
% YIN-SOURCE: id=YIN253A-C01-V-T000135; notes=253a:4; pdf=9; video=OY_napMPywE:00:38:56.240-00:39:18.050; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000135
% YIN-FORMULA-ID YIN253A-C01-F-000135
To compute $\langle\mathbf p|\mathbf p'\rangle$, write the ket as
$a^\dagger_{\mathbf p'}|\Omega\rangle$ and the bra as
$\langle\Omega|a_{\mathbf p}$.
% YIN-SPEECH-END YIN-OY-T000135
% YIN-SOURCE: id=YIN253A-C01-V-T000137; notes=253a:4; pdf=9; video=OY_napMPywE:00:39:18.060-00:39:40.750; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000137
% YIN-FORMULA-ID YIN253A-C01-F-000137
The commutation relation then replaces the product by the mixed commutator.
% YIN-SPEECH-END YIN-OY-T000137
% YIN-SOURCE: id=YIN253A-C01-V-T000139; notes=253a:4; pdf=9; video=OY_napMPywE:00:39:40.760-00:39:53.930; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000139
% YIN-FORMULA-ID YIN253A-C01-F-000139
I am simply choosing the normalization of the one-particle states so that their
overlap is the same delta function:
% YIN-SPEECH-END YIN-OY-T000139
% YIN-SOURCE: id=YIN253A-C01-U037; notes=253a:4; pdf=9; video=OY_napMPywE:00:38:00.260-00:39:53.930; class=NOTES_EXACT
\begin{equation}
  [a,a]=[a^{+},a^{+}]=0,
  \qquad
  [a_{\mathbf p},a_{\mathbf p'}^{+}]
  =\delta^{(D-1)}(\mathbf p-\mathbf p'),
  \qquad
  \braket{\mathbf p}{\mathbf p'}
  =\delta^{(D-1)}(\mathbf p-\mathbf p').
  \label{eq:253a-oscillator-normalization}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000141; notes=253a:4; pdf=9; video=OY_napMPywE:00:39:53.940-00:40:20.510; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000141
% YIN-FORMULA-ID YIN253A-C01-F-000141
Why does this delta function sometimes appear with an extra factor? That is a
matter of convention. We are free to rescale $a$ and $a^\dagger$, which changes
the normalization of the states. A
% YIN-SPEECH-END YIN-OY-T000141
% YIN-SOURCE: id=YIN253A-C01-V-T000143; notes=253a:4; pdf=9; video=OY_napMPywE:00:40:20.520-00:40:35.329; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000143
one-particle momentum eigenstate is a plane wave and, strictly speaking, is not
normalizable. A normalizable state is a wave packet formed by integrating these
momentum eigenstates
% YIN-SPEECH-END YIN-OY-T000143
% YIN-SOURCE: id=YIN253A-C01-V-T000145; notes=253a:4; pdf=9; video=OY_napMPywE:00:40:35.339-00:41:18.890; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000145
against a function. Its overall normalization remains a convention; one could
even rescale the basis by the energy to the one-third power, or whatever.
% YIN-SPEECH-END YIN-OY-T000145

% YIN-SOURCE: id=YIN253A-C01-V-T000149; notes=253a:3,4; pdf=8,9; video=OY_napMPywE:00:41:34.160-00:41:48.829; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000149
The annihilation operator reduces the particle number by one, just as the
creation operator increases it by one. The vacuum has zero particles by
definition.
% YIN-SPEECH-END YIN-OY-T000149
% YIN-SOURCE: id=YIN253A-C01-V-T000151; notes=253a:3; pdf=8; video=OY_napMPywE:00:41:48.839-00:42:24.050; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000151
Can we choose the vacuum energy however we want? Adding a constant to the
Hamiltonian would shift it, but we choose the vacuum energy to be zero. This is
the natural convention compatible with our Poincaré-invariant vacuum.
% YIN-SPEECH-END YIN-OY-T000151
% YIN-SOURCE: id=YIN253A-C01-V-T000153; notes=253a:3; pdf=8; video=OY_napMPywE:00:42:25.920-00:42:55.790; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000153
% YIN-FORMULA-ID YIN253A-C01-F-000153
The vacuum need not be unique. We assume that the chosen vacuum is
symmetry-invariant, meaning that every generator of the continuous symmetry
annihilates it. We will shortly see that $H$ is one of these generators.
% YIN-SPEECH-END YIN-OY-T000153

% YIN-SOURCE: id=YIN253A-C01-V-T000157; notes=253a:4; pdf=9; video=OY_napMPywE:00:43:00.920-00:43:21.309; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000157
Why do I introduce creation and annihilation operators? They let us write the
Hamiltonian directly in terms of these operators, without having to specify its
action on every basis state.
% YIN-SPEECH-END YIN-OY-T000157
% YIN-SOURCE: id=YIN253A-C01-V-T000159; notes=253a:4; pdf=9; video=OY_napMPywE:00:43:21.319-00:43:48.530; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000159
% YIN-FORMULA-ID YIN253A-C01-F-000159
In terms of $a$ and $a^\dagger$, the Hamiltonian is
% YIN-SPEECH-END YIN-OY-T000159
% YIN-SOURCE: id=YIN253A-C01-U043; notes=253a:4; pdf=9; video=OY_napMPywE:00:43:21.319-00:44:05.270; class=NOTES_EXACT
\begin{equation}
  H=\int d^{D-1}\mathbf p\,
  \sqrt{\mathbf p^{\,2}+m^2}\,
  a_{\mathbf p}^{+}a_{\mathbf p}.
  \label{eq:253a-free-hamiltonian}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000161; notes=253a:4; pdf=9; video=OY_napMPywE:00:43:48.540-00:44:05.270; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000161
% YIN-FORMULA-ID YIN253A-C01-F-000161
The operator $a^\dagger_{\mathbf p}a_{\mathbf p}$ measures the occupation number
at momentum $\mathbf p$. I will let you verify for yourself, using the
commutation relations, that this Hamiltonian produces the expected energy.
% YIN-SPEECH-END YIN-OY-T000161
% YIN-SOURCE: id=YIN253A-C01-V-T000165; notes=253a:4; pdf=9; video=OY_napMPywE:00:44:33.560-00:45:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000165
For massless particles, the requirement of finite particle number is much less
obvious. This subtlety is tied to infrared divergences in quantum
electrodynamics, and we may not reach it this semester.
% YIN-SPEECH-END YIN-OY-T000165

% YIN-SOURCE: id=YIN253A-C01-V-T000170; notes=253a:4; pdf=9; video=OY_napMPywE:00:45:07.500-00:45:31.800; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000170
We now have a well-defined Hilbert space and Hamiltonian. By design, this is a
quantum-mechanical system of free relativistic particles.
% YIN-SPEECH-END YIN-OY-T000170

% YIN-SOURCE: id=YIN253A-C01-V-T000174; notes=253a:4; pdf=9; video=OY_napMPywE:00:45:34.440-00:46:08.030; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000174
If you only want to describe free particles, meaning particles that do not
interact with one another, then we are done. You do not have to take this
course; you can go home. We would like to describe interactions. What about
interacting particles?
% YIN-SPEECH-END YIN-OY-T000174

% YIN-SOURCE: id=YIN253A-C01-V-T000176; notes=253a:4; pdf=9; video=OY_napMPywE:00:46:08.040-00:46:31.370; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000176
% YIN-FORMULA-ID YIN253A-C01-F-000176
You might say that this is not a big deal. Call the free Hamiltonian $H_0$.
Quantum mechanics allows us to add any Hermitian interaction term
$H_{\mathrm{int}}$.
% YIN-SPEECH-END YIN-OY-T000176
% YIN-SOURCE: id=YIN253A-C01-V-T000178; notes=253a:4; pdf=9; video=OY_napMPywE:00:46:31.380-00:47:15.170; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000178
% YIN-FORMULA-ID YIN253A-C01-F-000178
The interaction may contain operators such as $a^\dagger a^\dagger a$ or $a a
a^\dagger$, with appropriate momentum assignments. The first can annihilate one
particle and create two, thereby changing particle number.
% YIN-SPEECH-END YIN-OY-T000178
% YIN-SOURCE: id=YIN253A-C01-U046; notes=253a:4; pdf=9; video=OY_napMPywE:00:46:08.040-00:47:15.170; class=NOTES_EXACT
\begin{equation}
  H=H_0+
  \underbrace{H_{\mathrm{int}}}_{
    a^{+}a^{+}a,\;aaa^{+},\;\ldots}\, .
  \label{eq:253a-interaction-examples}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-N002; notes=253a:4; pdf=9; video=OY_napMPywE:00:46:08.040-00:47:23.030; class=EDITORIAL_NOTE
Momentum kernels and Hermitian-conjugate terms are understood so that
$H_{\mathrm{int}}$ is Hermitian.
% YIN-SOURCE: id=YIN253A-C01-V-T000180; notes=253a:4; pdf=9; video=OY_napMPywE:00:47:15.180-00:47:23.030; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000180
We can certainly write such terms. What is the big deal?
% YIN-SPEECH-END YIN-OY-T000180
% YIN-SOURCE: id=YIN253A-C01-V-T000182; notes=253a:4; pdf=9; video=OY_napMPywE:00:47:23.040-00:48:05.390; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000182
% YIN-FORMULA-ID YIN253A-C01-F-000182
The difficulty is preserving relativistic symmetry. It is possible to find an
$H_{\mathrm{int}}$ that respects it, but it is not easy.
% YIN-SPEECH-END YIN-OY-T000182

\subsection{Local disturbances and causality}
\label{sec:253a-causality}

% YIN-SOURCE: id=YIN253A-C01-V-T000185; notes=253a:5; pdf=10; video=OY_napMPywE:00:48:21.000-00:49:24.670; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000185
% YIN-FORMULA-ID YIN253A-C01-F-000185
Consider a disturbance at one point in space at time zero.
Figure~\ref{fig:253a-lightcone} shows its light cone in one spatial dimension.
We work in units where the speed of light is one, so light travels along rays at
forty-five-degree angles.
% YIN-SPEECH-END YIN-OY-T000185

slower than light. A trajectory outside the light cone would be superluminal and

% YIN-SPEECH-END YIN-OY-T000187

This kind of property is not built into the Hamiltonian formulation. Nothing

Let me quantify this a bit better in the language of local field operators.
% YIN-SPEECH-END YIN-OY-T000193
% YIN-SOURCE: id=YIN253A-C01-V-T000195; notes=253a:5; pdf=10; video=OY_napMPywE:00:51:19.319-00:52:17.630; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000195
Suppose an operation localized at one spacetime point changes the state of the
system. In a relativistic quantum-mechanical system, such a local disturbance
should be represented by a field operator.
% YIN-SPEECH-END YIN-OY-T000195

% YIN-SOURCE: id=YIN253A-C01-V-T000197; notes=253a:5; pdf=10; video=OY_napMPywE:00:52:17.640-00:52:48.109; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000197
% YIN-FORMULA-ID YIN253A-C01-F-000197
What does field mean here? All I mean is an operator $\hat\phi(x)$ that depends
on a spacetime point $x$. Like any quantum-mechanical operator, $\hat\phi(x)$
acts on the Hilbert space. We may take it to be Hermitian, so that its
expectation value is a physical observable.
% YIN-SPEECH-END YIN-OY-T000197
% YIN-SOURCE: id=YIN253A-C01-V-T000199; notes=253a:5; pdf=10; video=OY_napMPywE:00:52:48.119-00:53:15.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000199
% YIN-FORMULA-ID YIN253A-C01-F-000199
Unlike the operators familiar from undergraduate quantum mechanics, this is an
entire family of operators labeled by a parameter. I should emphasize that here
$x$ is a spacetime point, rather than an operator. The operator is $\hat\phi$.
% YIN-SPEECH-END YIN-OY-T000199
% YIN-SOURCE: id=YIN253A-C01-V-T000200; notes=253a:5; pdf=10; video=OY_napMPywE:00:53:15.000-00:53:39.470; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000200
% YIN-FORMULA-ID YIN253A-C01-F-000200
Thus $x^\mu=(x^0,\mathbf x)$ is just a label, a spacetime point. Associated with
each such point is an operator $\hat\phi(x)$ representing a local disturbance
of the system.
% YIN-SPEECH-END YIN-OY-T000200

\subsection{Poincar\'e covariance}
\label{sec:253a-poincare}

% YIN-SOURCE: id=YIN253A-C01-V-T000204; notes=253a:5; pdf=10; video=OY_napMPywE:00:53:52.020-00:54:06.770; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000204
Now, this field operator should obey some properties. We said these in words
earlier, but let me now say this more precisely.
% YIN-SPEECH-END YIN-OY-T000204
% YIN-SOURCE: id=YIN253A-C01-V-T000206; notes=253a:5; pdf=10; video=OY_napMPywE:00:54:06.780-00:54:34.849; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000206
% YIN-FORMULA-ID YIN253A-C01-F-000206
If I look at $\hat\phi(x)$ and $\hat\phi(x')$, at different spacetime points $x$
and $x'$, these two operators are supposed to be related by a Poincaré symmetry
that sends $x$ to $x'$.
% YIN-SPEECH-END YIN-OY-T000206
% YIN-SOURCE: id=YIN253A-C01-V-T000208; notes=253a:5; pdf=10; video=OY_napMPywE:00:54:34.859-00:55:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000208
% YIN-FORMULA-ID YIN253A-C01-F-000208
Since we are in Minkowski spacetime, I can always find some Poincaré
transformation that takes $x$ to $x'$. It could be a translation, a rotation, or
whatever. The choice is highly non-unique.
% YIN-SPEECH-END YIN-OY-T000208
% YIN-SOURCE: id=YIN253A-C01-V-T000209; notes=253a:5; pdf=10; video=OY_napMPywE:00:55:00.000-00:55:20.000; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000209
You'd expect that this symmetry taking $x$ to $x'$ should also take
$\hat\phi(x)$ to $\hat\phi(x')$. This is a reasonable requirement if you want to
say that $\hat\phi(x)$ is indeed tied to that spacetime point in some sense.
% YIN-SPEECH-END YIN-OY-T000209

% YIN-SOURCE: id=YIN253A-C01-V-T000210; notes=253a:5,6; pdf=10,11; video=OY_napMPywE:00:55:20.000-00:55:40.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000210
Consider a transformation that takes $x$ to $x'$:
% YIN-SPEECH-END YIN-OY-T000210
% YIN-SOURCE: id=YIN253A-C01-U056; notes=253a:6; pdf=11; video=OY_napMPywE:00:55:20.000-00:56:40.000; class=EQUATION_NORMALIZED
\begin{equation}
  x^\mu\rightsquigarrow x'^\mu
  =\Lambda^\mu{}_{\nu}x^\nu+a^\mu.
  \label{eq:253a-poincare-coordinate-map}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000211; notes=253a:6; pdf=11; video=OY_napMPywE:00:55:40.000-00:56:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000211
This says that you can shift $x$ by some constant spacetime vector $a^\mu$.
% YIN-SPEECH-END YIN-OY-T000211
% YIN-SOURCE: id=YIN253A-C01-V-T000212; notes=253a:6; pdf=11; video=OY_napMPywE:00:56:00.000-00:56:20.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000212
You can also rotate or boost, which is a Lorentz transformation
$\Lambda^\mu{}_\nu$.
% YIN-SPEECH-END YIN-OY-T000212
% YIN-SOURCE: id=YIN253A-C01-V-T000214; notes=253a:6; pdf=11; video=OY_napMPywE:00:56:40.000-00:57:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000214
The transformation matrix $\Lambda^\mu{}_\nu$ is supposed to preserve the
Lorentzian metric, so
% YIN-SPEECH-END YIN-OY-T000214
% YIN-SOURCE: id=YIN253A-C01-U056B; notes=253a:6; pdf=11; video=OY_napMPywE:00:56:00.000-00:56:40.000; class=EQUATION_NORMALIZED
\begin{equation}
  \eta^{\alpha\beta}\Lambda^\mu{}_{\alpha}\Lambda^\nu{}_{\beta}
  =\eta^{\mu\nu},
  \qquad
  \eta^{\mu\nu}
  =\operatorname{diag}\left(-1,1,\ldots,1\right),
  \label{eq:253a-lorentz-metric}
\end{equation}
% YIN-SOURCE: id=YIN253A-C01-U056C; notes=253a:6; pdf=11; video=OY_napMPywE:00:56:00.000-00:57:00.000; class=EQUATION_NORMALIZED
where we're using the mostly-positive signature for the Lorentzian metric in
$D$ dimensions.

% YIN-SOURCE: id=YIN253A-C01-V-T000215; notes=253a:6; pdf=11; video=OY_napMPywE:00:57:00.000-00:57:20.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000215
This is the usual Poincaré transformation from special relativity. In your
freshman mechanics class, Poincaré symmetry acts on spacetime points. In quantum
mechanics, the same symmetry is represented by a unitary operator.

% YIN-SOURCE: id=YIN253A-C01-V-T000216; notes=253a:6; pdf=11; video=OY_napMPywE:00:57:20.000-00:57:40.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000216
Here the Poincaré symmetry acts on states in the Hilbert space. The
% YIN-SPEECH-END YIN-OY-T000216
% YIN-SOURCE: id=YIN253A-C01-V-T000217; notes=253a:6; pdf=11; video=OY_napMPywE:00:57:40.000-00:58:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000217

% YIN-SPEECH-END YIN-OY-T000217
% YIN-SOURCE: id=YIN253A-C01-V-T000218; notes=253a:6; pdf=11; video=OY_napMPywE:00:58:00.000-00:58:20.000; class=SPEECH_CLEAN

Since the transformation is specified by the Lorentz matrix $\Lambda$ and the

% YIN-SPEECH-END YIN-OY-T000218

% YIN-SOURCE: id=YIN253A-C01-V-T000219; notes=253a:6; pdf=11; video=OY_napMPywE:00:58:20.000-00:58:40.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000219
In particular, we need to say how $U$ acts on a field operator.
% YIN-SPEECH-END YIN-OY-T000219
% YIN-SOURCE: id=YIN253A-C01-V-T000220; notes=253a:6; pdf=11; video=OY_napMPywE:00:58:40.000-00:59:00.000; class=SPEECH_CLEAN

A state is transformed by $U$, while an operator is transformed by conjugation

% YIN-SPEECH-END YIN-OY-T000220
% YIN-SOURCE: id=YIN253A-C01-V-T000221; notes=253a:6; pdf=11; video=OY_napMPywE:00:59:00.000-00:59:20.000; class=SOURCE_COMPOSITE

  \hat\phi(\Lambda x+a)

  \label{eq:253a-scalar-covariance}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000222; notes=253a:6; pdf=11; video=OY_napMPywE:00:59:20.000-00:59:40.000; class=SOURCE_COMPOSITE

% YIN-SPEECH-END YIN-OY-T000222
% YIN-SOURCE: id=YIN253A-C01-V-T000223; notes=253a:6; pdf=11; video=OY_napMPywE:00:59:40.000-01:00:00.000; class=SOURCE_COMPOSITE

% YIN-SPEECH-END YIN-OY-T000223

% YIN-SOURCE: id=YIN253A-C01-V-T000224; notes=253a:6; pdf=11; video=OY_napMPywE:01:00:00.000-01:00:20.000; class=SPEECH_CLEAN

% YIN-SPEECH-END YIN-OY-T000224

it depends on $\Lambda$ and $a$. One way to
% YIN-SPEECH-END YIN-OY-T000227

% YIN-SPEECH-END YIN-OY-T000228
% YIN-SOURCE: id=YIN253A-C01-V-T000229; notes=253a:6; pdf=11; video=OY_napMPywE:01:01:40.000-01:02:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000229

% YIN-SPEECH-END YIN-OY-T000229
% YIN-SOURCE: id=YIN253A-C01-V-T000230; notes=253a:6; pdf=11; video=OY_napMPywE:01:02:00.000-01:02:20.000; class=SPEECH_CLEAN

\begin{equation}
  \Lambda^\mu{}_{\nu}=\delta^\mu{}_{\nu}+\omega^\mu{}_{\nu},
  \qquad
  a^\mu=\epsilon^\mu.
  \label{eq:253a-infinitesimal-poincare}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000231; notes=253a:6; pdf=11; video=OY_napMPywE:01:02:20.000-01:02:40.000; class=SPEECH_CLEAN

Substituting $\Lambda=\delta+\omega$ into the metric-preserving condition and
expanding to first order shows that $\omega_{\mu\nu}$, with one index
% YIN-SPEECH-END YIN-OY-T000231
% YIN-SOURCE: id=YIN253A-C01-V-T000232; notes=253a:6; pdf=11; video=OY_napMPywE:01:02:40.000-01:03:00.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000232
lowered by $\eta_{\mu\nu}$, is antisymmetric:
$\omega_{\mu\nu}=-\omega_{\nu\mu}$.
% YIN-SPEECH-END YIN-OY-T000232

% YIN-SOURCE: id=YIN253A-C01-V-T000234; notes=253a:6; pdf=11; video=OY_napMPywE:01:03:20.000-01:03:40.000; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000234
The unitary operator $U$ is also close to the identity. To first order in
$\omega$ and $\epsilon$, it is the identity plus an anti-Hermitian operator. A
% YIN-SPEECH-END YIN-OY-T000234

% YIN-SPEECH-END YIN-OY-T000235

% YIN-SPEECH-END YIN-OY-T000236
% YIN-SOURCE: id=YIN253A-C01-V-T000237; notes=253a:6; pdf=11; video=OY_napMPywE:01:04:20.000-01:04:40.000; class=SPEECH_CLEAN

% YIN-SOURCE: id=YIN253A-C01-V-T000243; notes=253a:6; pdf=11; video=OY_napMPywE:01:06:12.200-01:06:24.359; class=SPEECH_CLEAN

% YIN-SOURCE: id=YIN253A-C01-V-T000244; notes=253a:6; pdf=11; video=OY_napMPywE:01:06:24.359-01:06:38.400; class=SPEECH_CLEAN

% YIN-FORMULA-ID YIN253A-C01-F-000244

\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000247; notes=253a:6; pdf=11; video=OY_napMPywE:01:07:33.240-01:07:45.359; class=SPEECH_CLEAN

We will not derive here

  U(\Lambda',a')U(\Lambda,a)

\end{equation}

\subsection{Microcausality and the free scalar field}
\label{sec:253a-microcausality}

% YIN-SOURCE: id=YIN253A-C01-V-T000262; notes=253a:6; pdf=11; video=OY_napMPywE:01:11:17.520-01:11:32.960; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000262
% YIN-FORMULA-ID YIN253A-C01-F-000262
The point of this little discussion is to explain what it means for $\hat\phi$
to be tied to the spacetime point $x$: the Poincaré
% YIN-SPEECH-END YIN-OY-T000262
% YIN-SOURCE: id=YIN253A-C01-V-T000263; notes=253a:6; pdf=11; video=OY_napMPywE:01:11:32.960-01:11:46.140; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000263
% YIN-FORMULA-ID YIN253A-C01-F-000263
transformation represented by $U$ carries $\hat\phi(x)$ to $\hat\phi(\Lambda
x+a)$.
% YIN-SPEECH-END YIN-OY-T000263

% YIN-SOURCE: id=YIN253A-C01-V-T000264; notes=253a:6,7; pdf=11,12; video=OY_napMPywE:01:11:46.140-01:12:07.440; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000264
So far I have not said anything about locality, and that is going to be the key.
The further requirement is microcausality.
% YIN-SPEECH-END YIN-OY-T000264
% YIN-SOURCE: id=YIN253A-C01-V-T000265; notes=253a:7; pdf=12; video=OY_napMPywE:01:12:07.440-01:12:25.380; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000265
% YIN-FORMULA-ID YIN253A-C01-F-000265
For the present scalar operator, we demand that $\hat\phi(x)$ and $\hat\phi(y)$

% YIN-SPEECH-END YIN-OY-T000265
% YIN-SOURCE: id=YIN253A-C01-V-T000266; notes=253a:7; pdf=12; video=OY_napMPywE:01:12:25.380-01:12:38.480; class=SPEECH_CLEAN

% YIN-FORMULA-ID YIN253A-C01-F-000267
With our mostly-positive convention, the Lorentzian inner product is

% YIN-SOURCE: id=YIN253A-C01-V-T000268; notes=253a:7; pdf=12; video=OY_napMPywE:01:12:57.900-01:13:08.699; class=SPEECH_CLEAN

\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000270; notes=253a:7; pdf=12; video=OY_napMPywE:01:13:21.960-01:13:31.800; class=SPEECH_CLEAN

% YIN-SPEECH-END YIN-OY-T000270

% YIN-SOURCE: id=YIN253A-C01-V-T000272; notes=253a:7; pdf=12; video=OY_napMPywE:01:13:38.760-01:13:53.820; class=SPEECH_CLEAN

Does this apply to our system of free particles? Intuitively it should: the

Lower-case $p$ is the integration variable, while capital $P$ denotes the
operator. Together the Hamiltonian and spatial momentum form the energy-momentum
operator $\hat P^\mu=(H,\mathbf P)$.
% YIN-SPEECH-END YIN-OY-T000281
% YIN-SOURCE: id=YIN253A-C01-U076C; notes=253a:7; pdf=12; video=OY_napMPywE:01:15:19.980-01:15:43.550; class=NOTES_EXACT
\begin{equation}
  \hat P^\mu=(H,\mathbf P).
  \label{eq:253a-free-energy-momentum-generator}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000283; notes=253a:7; pdf=12; video=OY_napMPywE:01:15:43.560-01:15:58.550; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000283

These are some of the symmetry generators of the model. The $J$'s are more

% YIN-SOURCE: id=YIN253A-C01-V-T000285; notes=253a:7; pdf=12; video=OY_napMPywE:01:15:58.560-01:16:09.239; class=SOURCE_COMPOSITE

% YIN-SOURCE: id=YIN253A-C01-V-T000289; notes=253a:7; pdf=12; video=OY_napMPywE:01:16:27.480-01:16:38.760; class=SOURCE_COMPOSITE

% YIN-SOURCE: id=YIN253A-C01-V-T000293; notes=253a:7; pdf=12; video=OY_napMPywE:01:16:56.840-01:17:04.550; class=SPEECH_CLEAN

It exists. It is not unique, but here is one choice, written in terms of the
$a_{\mathbf p}$'s.
% YIN-SPEECH-END YIN-OY-T000293
% YIN-SOURCE: id=YIN253A-C01-V-T000295; notes=253a:7; pdf=12; video=OY_napMPywE:01:17:04.560-01:17:19.689; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000295
% YIN-FORMULA-ID YIN253A-C01-F-000295
The overall normalization is not too important here. This quantity is
important: $\omega_{\mathbf p}$ is the positive-energy relativistic dispersion
relation for a particle of mass $m$:
% YIN-SPEECH-END YIN-OY-T000295
% YIN-SOURCE: id=YIN253A-C01-U080; notes=253a:7; pdf=12; video=OY_napMPywE:01:17:19.699-01:17:42.360; class=NOTES_EXACT
\begin{equation}
  \hat\phi(x)=
  \int\frac{d^{D-1}\mathbf p}
  {\sqrt{(2\pi)^{D-1}2\omega_{\mathbf p}}}
  \left(
    a_{\mathbf p}e^{\ii p\cdot x}
    +a_{\mathbf p}^{+}e^{-\ii p\cdot x}
  \right).
  \label{eq:253a-free-scalar-expansion}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-U081; notes=253a:8; pdf=13; video=OY_napMPywE:01:17:04.560-01:18:04.729; class=NOTES_EXACT
\begin{equation}
  p\cdot x\equiv\mathbf p\cdot\mathbf x-\omega_{\mathbf p}x^0,
  \qquad
  \omega_{\mathbf p}\equiv\sqrt{\mathbf p^{\,2}+m^2}.
  \label{eq:253a-free-scalar-definitions}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-V-T000297; notes=253a:7,8; pdf=12,13; video=OY_napMPywE:01:17:19.699-01:17:42.360; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000297
% YIN-FORMULA-ID YIN253A-C01-F-000297
The field operator is the momentum integral above, with $p\cdot
x=\mathbf p\cdot\mathbf x-\omega_{\mathbf p}x^0$.
% YIN-SPEECH-END YIN-OY-T000297
% YIN-SOURCE: id=YIN253A-C01-V-T000299; notes=253a:7,8; pdf=12,13; video=OY_napMPywE:01:17:57.020-01:18:04.729; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000299
% YIN-FORMULA-ID YIN253A-C01-F-000299
The integral runs over $\mathbf p$, and $\omega_{\mathbf p}$ is its energy
according to the dispersion relation, by inspection.
% YIN-SPEECH-END YIN-OY-T000299
% YIN-SOURCE: id=YIN253A-C01-V-T000301; notes=253a:7,8; pdf=12,13; video=OY_napMPywE:01:18:04.739-01:18:19.070; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000301
I invite you to think about this for yourself. We will understand the
construction much more systematically later.
% YIN-SPEECH-END YIN-OY-T000301

% YIN-SOURCE: id=YIN253A-C01-V-T000303; notes=253a:8,9; pdf=13,14; video=OY_napMPywE:01:18:19.080-01:18:35.390; class=SOURCE_COMPOSITE
% YIN-SPEECH-BEGIN YIN-OY-T000303
% YIN-FORMULA-ID YIN253A-C01-F-000303
This construction has all the nice properties we just imagined. It transforms
correctly under Poincaré transformations and, importantly, obeys microcausality.
% YIN-SPEECH-END YIN-OY-T000303

% YIN-SOURCE: id=YIN253A-C01-U084; notes=253a:8; pdf=13; video=none; class=NOTES_EXACT
To check microcausality, compute the commutator:

% YIN-SOURCE: id=YIN253A-C01-U085; notes=253a:8; pdf=13; video=none; class=NOTES_EXACT
\begin{equation}
  [\hat\phi(x),\hat\phi(y)]
  =\int\frac{d^{D-1}\mathbf p}{(2\pi)^{D-1}2\omega_{\mathbf p}}
  \mathbin{\cdot}
  \left[e^{\ii p\cdot(x-y)}-e^{-\ii p\cdot(x-y)}\right].
  \label{eq:253a-free-field-commutator}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-U086; notes=253a:8; pdf=13; video=none; class=EQUATION_NORMALIZED
\begin{equation}
  [\hat\phi(x),\hat\phi(y)]
  =\int
  \underbrace{\frac{d^D p}{(2\pi)^{D-1}}
    \theta(p^0)\delta(p^2+m^2)}_{
      \substack{\text{invariant for}\\
      \Lambda\in SO^+(1,D-1)}}
  \underbrace{\left[e^{\ii p\cdot(x-y)}-e^{-\ii p\cdot(x-y)}\right]}_{
      \substack{\text{scalar under simultaneous}\\
      p\to\Lambda p,\ (x-y)\to\Lambda(x-y)}}
  .
  \label{eq:253a-covariant-commutator}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-U087; notes=253a:8; pdf=13; video=none; class=SOURCE_COMPOSITE
Under a proper orthochronous Lorentz transformation, both $p$ and
$z=x-y$ transform; changing the integration variable leaves the integral
invariant.  For spacelike $z$, choose a Lorentz frame with $z^0=0$ and
$\mathbf z\ne0$.  The integrand is odd under $\mathbf p\to-\mathbf p$, so the
integral vanishes.

% YIN-SOURCE: id=YIN253A-C01-U088; notes=253a:8; pdf=13; video=none; class=NOTES_EXACT
\begin{equation}
  [\hat\phi(x),\hat\phi(y)]=0
  \qquad\text{for}\qquad (x-y)^2>0.
  \label{eq:253a-free-field-microcausality}
\end{equation}

% YIN-SOURCE: id=YIN253A-C01-U089; notes=253a:9; pdf=14; video=OY_napMPywE:01:18:19.080-01:18:35.390; class=SOURCE_COMPOSITE
The free field is also required to obey the covariance property below.  Its
direct verification is deferred until the systematic construction.

% YIN-SOURCE: id=YIN253A-C01-U090; notes=253a:9; pdf=14; video=OY_napMPywE:01:18:19.080-01:18:35.390; class=NOTES_EXACT
\begin{equation}
  U(\Lambda,a)\,\hat\phi(x)\,\bigl(U(\Lambda,a)\bigr)^{-1}
  =\hat\phi(\Lambda x+a).
  \label{eq:253a-free-field-covariance}
\end{equation}

\subsection{Postulates and the next formulation}
\label{sec:253a-postulates}

% YIN-SOURCE: id=YIN253A-C01-U091; notes=253a:9; pdf=14; video=none; class=NOTES_EXACT
We therefore postulate that a system of interacting relativistic particles has
the same structure:
\begin{itemize}
  \setlength{\itemsep}{2pt}
  \setlength{\parsep}{0pt}
  \setlength{\topsep}{3pt}
  \item a Hilbert space $\mathcal H$;
  \item Poincar\'e symmetry $U(\Lambda,a)$;
  \item a Poincar\'e-invariant vacuum $\ket{\Omega}$;
  \item local \textquotedblleft field\textquotedblright\ operators
    $\hat\phi(x)$ obeying Poincar\'e covariance and microcausality.
\end{itemize}

% YIN-SOURCE: id=YIN253A-C01-V-T000306; notes=253a:9; pdf=14; video=OY_napMPywE:01:18:44.000-01:19:07.669; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000306
An interacting system with the same properties is difficult to construct in the
Hamiltonian formalism. The basic reason is that this formalism singles out time
from space, so Poincaré symmetry is not manifest.
% YIN-SPEECH-END YIN-OY-T000306
% YIN-SOURCE: id=YIN253A-C01-V-T000308; notes=253a:9; pdf=14; video=OY_napMPywE:01:19:07.679-01:19:26.450; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000308
For example, our integrals over spatial momentum do not look Lorentz covariant,
even when the underlying physics is Lorentz invariant. Operators can be
constructed, but checking the symmetry is not trivial.
% YIN-SPEECH-END YIN-OY-T000308
% YIN-SOURCE: id=YIN253A-C01-V-T000310; notes=253a:9; pdf=14; video=OY_napMPywE:01:19:26.460-01:19:47.090; class=SPEECH_CLEAN
% YIN-SPEECH-BEGIN YIN-OY-T000310
It will therefore be useful to have a formulation in which Poincaré symmetry is
manifest. This is why the Lagrangian formalism will be useful. We will next
formulate quantum mechanics in the Lagrangian language.
% YIN-SPEECH-END YIN-OY-T000310
