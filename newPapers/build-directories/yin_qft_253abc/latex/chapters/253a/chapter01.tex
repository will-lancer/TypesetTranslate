% YIN-SOURCE: id=YIN253A-C01-U091; notes=253a:9; pdf=14; video=none; class=NOTES_EXACT
The handwritten source postulates that the same properties hold for a system
of interacting relativistic particles:
\begin{itemize}
  \setlength{\itemsep}{2pt}
  \setlength{\parsep}{0pt}
  \setlength{\topsep}{3pt}
  \item a Hilbert space $\mathcal H$;
  \item Poincar\'e symmetry $U(\Lambda,a)$;
  \item a Poincar\'e-invariant vacuum $\ket{\Omega}$;
  \item local \textquotedblleft field\textquotedblright\ operators
    $\hat\phi(x)$ obeying Poincar\'e covariance and microcausality.
\end{itemize}
