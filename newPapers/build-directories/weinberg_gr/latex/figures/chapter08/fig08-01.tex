% Source: Weinberg GR, physical PDF p. 212 (printed p. 189).
% Coverage: Figure 8.1, geometry of solar light deflection.
% Status: vector reconstruction; source-reviewed and compile-clean.
% Geometry: the ray is an exact Keplerian hyperbola about the focus at the
%           sun's centre, drawn as r(psi) = p/(1 + e cos psi) with the point
%           (r sin psi, -r cos psi), so psi is measured from perihelion and
%           perihelion lies straight below the sun.  Taking the deflection
%           Delta phi = 50 degrees fixes the half-sweep
%           psi_max = (180 + Delta phi)/2 = 115 deg, hence e = -1/cos psi_max
%           = 2.3662; with r_0 = 1.6 this gives p = r_0 (1 + e) = 5.3859 and
%           an impact parameter b = a sqrt(e^2 - 1) = 2.5115, a = p/(e^2 - 1).
%           The thin straight line is the true incoming asymptote: direction
%           psi_max - 90 deg = 25 deg at perpendicular distance b from the
%           centre.  The angle it makes with the outgoing branch is therefore
%           exactly Delta phi, and the two asymptotes cross at
%           (0, -b/cos 25 deg) = (0, -2.7711), which is the centre of the
%           Delta phi arc.
% Uncertainties: none; deflection is deliberately exaggerated as in source.
