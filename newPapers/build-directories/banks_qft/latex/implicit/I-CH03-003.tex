\begin{exercise}[Fourier solution of the finite Schwinger--Dyson equations]{I-CH03-003}
Regulate the field theory to finitely many real variables and set
\[
 Z[J]=\int\dd^N\phi\,\ee^{\ii S(\phi)+\ii J_A\phi^A}.
\]
Assume that boundary terms in $\phi$ vanish.  Work out the Fourier-transform
rules for $\partial/(\ii\partial J_A)$ and multiplication by $J_A$.  Apply
them to the finite-dimensional Schwinger--Dyson equation with the source sign
consistent with the exponent $+\ii J_A\phi^A$,
\[
 K_{AB}\frac{\partial Z}{\ii\partial J_B}
 =\left[
 V'\!\left(\frac{\partial}{\ii\partial J_A}\right)-J_A
 \right]Z,
\]
and derive
\[
 \frac{\partial S}{\partial\phi^A}
 =K_{AB}\phi^B-\frac{\partial V}{\partial\phi^A}.
\]
Integrate this system for symmetric $K_{AB}$, identify the undetermined
constant, and check the result by substitution.  Also explain how reversing
the Fourier-kernel sign changes the source sign in the differential equation,
and reconcile this result with the $+J_A$ printed in Eq.~\eqref{eq:3.10}.
\end{exercise}
