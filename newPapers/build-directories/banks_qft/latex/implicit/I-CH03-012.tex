\begin{exercise}[Momentum-space and Euclidean rules]{I-CH03-012}
Start with a real scalar theory with
\[
 \mathcal L_0=-\frac12(\partial\phi)^2-\frac12m^2\phi^2
\]
and Lorentzian interaction Lagrangian
\[
 \mathcal L_I=-g\sum_k\frac{v_k}{k!}\phi^k(x),
\]
and use the Fourier convention
\(D_F(x)=\int\dd^D p\,\ee^{+\ii p\mathbin{\cdot}x}\widetilde D_F(p)/(2\pi)^D\).
Derive the momentum-space rules from the position-space Wick expansion.
Account for every vertex delta function, the one overall conservation delta
function, the measure for each independent loop momentum, derivative
interactions, propagator factors, and symmetry numbers.  Show for a connected
graph that the number of loop integrations is $L=I-V+1$.  Wick rotate the
same expression and derive the Euclidean propagator and vertex signs from
$\ee^{\ii S_M}\to\ee^{-S_E}$.
\end{exercise}
