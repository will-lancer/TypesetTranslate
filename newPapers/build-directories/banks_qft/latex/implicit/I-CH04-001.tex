\begin{exercise}[The Proca field cannot have Fermi statistics]{I-CH04-001}
Use the Minkowski-space Proca two-point function
\begin{equation*}
 D_{\mu\nu}(x-y)
 =\int\frac{\dd^D p}{(2\pi)^D}\,
 \frac{-\ii\bigl(\eta_{\mu\nu}+p_\mu p_\nu/\mu^2\bigr)}
 {p^2+\mu^2-\ii\epsilon}\,
 \ee^{+\ii p\cdot(x-y)}
\end{equation*}
to prove that a Hermitian massive vector field cannot consistently be
quantized as a fermion.  Compare the exchange symmetry of this kernel with
the exchange rule for the time-ordered two-point function of two odd fields.
Give the equivalent argument in the source functional: take the source to be
Grassmann odd and determine what a symmetric quadratic kernel contributes to
the Gaussian exponent.
\end{exercise}
