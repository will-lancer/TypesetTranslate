1. Draw the integral curves corresponding to a vector field in R2 with components, in
Cartesian coordinates, given by

   • X µ = (y, −x)

   • X µ = (x − y, x + y)

[Hint: you might find life easier in polar coordinates.]

2. Let Ĥ : Tp (M ) → Tp∗ (M ) be a linear map. Define

                                 H(X, Y ) = [Ĥ(Y )](X)

Show that this map is linear in both arguments (e.g. H(f X + gY, Z) = f H(X, Z) +
gH(Y, Z) for f, g ∈ C and X, Y, Z ∈ Tp (M )) and hence defines a rank (0, 2) tensor.
  Similarly, show that a linear map Tp (M ) → Tp (M ) defines a tensor of rank (1, 1). What
tensor δ arises from the identity map?

3*. Let M be a manifold and f : M → R be a smooth function such that df = 0 at some
point p ∈ M . Let xµ be a coordinate chart defined in a neighbourhood of p. Define

                                               ∂ 2f

By considering the transformation law for components show that Fµν defines a rank (0, 2)
tensor. (This is called the Hessian of f at p.) Construct also a coordinate-free definition
and demonstrate its tensorial properties.

4. Let gµν be a rank (0, 2) tensor. In a basis, one can regard the components gµν as
elements of an n × n matrix, so that one may define the determinant g = det(gµν ). How
does g transform under a change of basis?
