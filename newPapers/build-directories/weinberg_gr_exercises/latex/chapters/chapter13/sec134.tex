\subsection{Tensors in a Maximally Symmetric Space}\label{sec:13.4}

The assumption of maximal symmetry can be applied, not only to the metric of
a space, but to any tensor fields that inhabit the space. A tensor field
\(T_{\mu\nu\ldots}\) is said to be \emph{form-invariant} under a
transformation \(x\longrightarrow x'\) if
\(T'_{\mu\nu\ldots}(x')\) is the same function of its argument \(x'^\mu\)
as \(T_{\mu\nu\ldots}(x)\) was of its argument \(x^\mu\), that is,
\begin{equation}
  T'_{\mu\nu\ldots}(y)
  =
  T_{\mu\nu\ldots}(y)
  \qquad\text{for all \(y\).}
  \tag{13.4.1}\label{eq:13.4.1}
\end{equation}
At any given point, the transformed tensor is given by the usual formula
\[
  T_{\mu\nu\ldots}(x)
  =
  \frac{\partial x'^\rho}{\partial x^\mu}
  \frac{\partial x'^\sigma}{\partial x^\nu}
  \cdots
  T'_{\rho\sigma\ldots}(x'),
\]
so the form-invariance condition \eqref{eq:13.4.1} reads
\begin{equation}
  T_{\mu\nu\ldots}(x)
  =
  \frac{\partial x'^\rho}{\partial x^\mu}
  \frac{\partial x'^\sigma}{\partial x^\nu}
  \cdots
  T_{\rho\sigma\ldots}(x').
  \tag{13.4.2}\label{eq:13.4.2}
\end{equation}
For an infinitesimal transformation
\[
  x'^\mu=x^\mu+\epsilon\xi^\mu(x),
  \qquad
  \lvert\epsilon\rvert\ll1,
\]
the condition \eqref{eq:13.4.2} becomes, to first order in \(\epsilon\),
\begin{equation}
  \begin{aligned}
  0={}&
  \partial_\mu\xi^\rho\,T_{\rho\nu\ldots}
  +\partial_\nu\xi^\sigma\,T_{\mu\sigma\ldots}
  +\cdots
  +\xi^\lambda\partial_\lambda T_{\mu\nu\ldots}.
  \end{aligned}
  \tag{13.4.3}\label{eq:13.4.3}
\end{equation}
(That is, the Lie derivative of \(T_{\mu\nu\ldots}\) with respect to
\(\xi^\lambda\) vanishes; see Section~\ref{sec:10.9}.) A tensor in a
maximally symmetric space, which satisfies \eqref{eq:13.4.3} for all
\(N(N+1)/2\) independent Killing vectors \(\xi^\lambda(x)\), will be called
\emph{maximally form-invariant}.

For a scalar \(S(x)\), Eq.~\eqref{eq:13.4.3} reads simply
\begin{equation}
  \xi^\lambda(x)\partial_\lambda S(x)=0.
  \tag{13.4.4}\label{eq:13.4.4}
\end{equation}
If the scalar is maximally form-invariant, then \(\xi^\lambda(x)\) can at
any given point be chosen to have any value we like, and
\eqref{eq:13.4.4} therefore requires that \(S\) be constant:
\begin{equation}
  \partial_\lambda S=0.
  \tag{13.4.5}\label{eq:13.4.5}
\end{equation}

For any other maximally form-invariant tensor, it is convenient first to
choose a Killing vector \(\xi^\lambda(x)\) that at a given point \(X\)
satisfies
\[
  \xi^\lambda(X)=0
\]
and for which the quantities
\[
  \nabla_\mu\xi_\sigma(X)
  =
  g_{\sigma\rho}(X)
  \left.\partial_\mu\xi^\rho(x)\right|_{x=X}
\]
form an arbitrary antisymmetric matrix. Equation~\eqref{eq:13.4.3} then
reads, at \(x=X\),
\[
  0
  =
  \nabla_\tau\xi_\sigma
  \left(
    \delta_\mu^\tau T^\sigma{}_{\nu\ldots}
    +\delta_\nu^\tau T_\mu{}^\sigma{}_{\ldots}
    +\cdots
  \right).
\]
Since \(\nabla_\tau\xi_\sigma\) is an arbitrary antisymmetric matrix, its
coefficient must be symmetric in \(\sigma\) and \(\tau\):
\begin{align}
  &\delta_\mu^\tau T^\sigma{}_{\nu\ldots}
  +\delta_\nu^\tau T_\mu{}^\sigma{}_{\ldots}
  +\cdots
  \notag\\
  &\qquad =
  \delta_\mu^\sigma T^\tau{}_{\nu\ldots}
  +\delta_\nu^\sigma T_\mu{}^\tau{}_{\ldots}
  +\cdots.
  \tag{13.4.6}\label{eq:13.4.6}
\end{align}
Since \(X\) was arbitrary, this must hold everywhere.

For a maximally form-invariant vector \(A_\mu(x)\),
Eq.~\eqref{eq:13.4.6} reads
\[
  \delta_\mu^\tau A^\sigma
  =
  \delta_\mu^\sigma A^\tau.
\]
Contracting \(\tau\) with \(\mu\), we find that in \(N\) dimensions
\[
  NA^\sigma=A^\sigma,
\]
so, except for the trivial case \(N=1\), we must have
\begin{equation}
  A^\sigma=0.
  \tag{13.4.7}\label{eq:13.4.7}
\end{equation}

For a maximally form-invariant tensor \(B_{\mu\nu}\) of second rank,
Eq.~\eqref{eq:13.4.6} reads
\[
  \delta_\mu^\tau B^\sigma{}_\nu
  +\delta_\nu^\tau B_\mu{}^\sigma
  =
  \delta_\mu^\sigma B^\tau{}_\nu
  +\delta_\nu^\sigma B_\mu{}^\tau.
\]
Contracting \(\tau\) with \(\mu\) gives
\[
  NB^\sigma{}_\nu+B_\nu{}^\sigma
  =
  B^\sigma{}_\nu+\delta_\nu^\sigma B^\mu{}_\mu,
\]
or, lowering the \(\sigma\) index,
\begin{equation}
  (N-1)B_{\sigma\nu}+B_{\nu\sigma}
  =
  g_{\sigma\nu}B^\mu{}_\mu.
  \tag{13.4.8}\label{eq:13.4.8}
\end{equation}
Subtracting the same equation with \(\nu\) and \(\sigma\) interchanged
yields
\[
  (N-2)\left(B_{\sigma\nu}-B_{\nu\sigma}\right)=0,
\]
so as long as \(N\neq2\), the tensor \(B_{\sigma\nu}\) must be symmetric:
\begin{equation}
  B_{\sigma\nu}=B_{\nu\sigma}.
  \tag{13.4.9}\label{eq:13.4.9}
\end{equation}
(In two dimensions, \(B_{\sigma\nu}\) can have an antisymmetric part
proportional to \(\lvert g\rvert^{-1/2}\tilde\epsilon_{\sigma\nu}\); see
Section~\ref{sec:4.4}.) Using \eqref{eq:13.4.9} in
\eqref{eq:13.4.8} gives now for \(N\geq3\) (and for the symmetric part of
\(B_{\sigma\nu}\) for \(N=2\))
\begin{equation}
  B_{\sigma\nu}=f g_{\sigma\nu},
  \tag{13.4.10}\label{eq:13.4.10}
\end{equation}
where
\[
  f\equiv\frac1N B^\mu{}_\mu.
\]

To determine the dependence of \(f\) on the coordinates, we can use
\eqref{eq:13.4.10} back in the form-invariance condition
\eqref{eq:13.4.3}:
\[
  0
  =
  \partial_\mu\xi^\rho\,f g_{\rho\nu}
  +\partial_\nu\xi^\sigma\,f g_{\mu\sigma}
  +\xi^\lambda\partial_\lambda(fg_{\mu\nu}).
\]
But \(g_{\mu\nu}\) satisfies the Killing condition \eqref{eq:13.1.4}, so
this becomes
\[
  0=g_{\mu\nu}\xi^\lambda\partial_\lambda f.
\]
In a maximally symmetric space we can at any given point choose
\(\xi^\lambda\) to have any value we like, and therefore
\begin{equation}
  \partial_\lambda f=0.
  \tag{13.4.11}\label{eq:13.4.11}
\end{equation}
Thus \emph{the only maximally form-invariant tensor of second rank is the
metric tensor, times a possible constant}.
