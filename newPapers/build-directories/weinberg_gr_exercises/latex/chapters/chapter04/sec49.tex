\subsection{Covariant Differentiation Along a Curve}\label{sec:4.9}

This chapter has dealt until now with tensor fields defined over all
spacetime; we now consider tensors \(T(\tau)\) defined only over a curve
\(x^\mu(\tau)\). Obvious examples come to mind, such as the momentum
\(P^\mu(\tau)\) or spin \(S_\mu(\tau)\) of a single particle. For such
tensors it would of course be meaningless to talk about covariant
differentiation with respect to \(x^\mu\), but we can define a covariant
derivative with respect to the invariant parameter \(\tau\) that parametrizes
the curve.

Consider first a contravariant vector \(A^\mu(\tau)\), with transformation
rule
\begin{equation}
  A'^\mu(\tau)
  =
  \frac{\partial x'^\mu}{\partial x^\nu}A^\nu(\tau).
  \tag{4.9.1}\label{eq:4.9.1}
\end{equation}
It should be noted that the Jacobian is to be evaluated at
\(x^\mu=x^\mu(\tau)\), so that it depends on \(\tau\). Therefore,
differentiating with respect to \(\tau\), we find two terms:
\begin{equation}
  \frac{\dd A'^\mu}{\dd\tau}
  =
  \frac{\partial x'^\mu}{\partial x^\nu}
  \frac{\dd A^\nu}{\dd\tau}
  +
  \frac{\partial^2x'^\mu}
       {\partial x^\nu\,\partial x^\lambda}
  \frac{\dd x^\lambda}{\dd\tau}A^\nu.
  \tag{4.9.2}\label{eq:4.9.2}
\end{equation}
The second derivative of \(x'^\mu\) is the same as that responsible for the
inhomogeneous term in the transformation formula \eqref{eq:4.5.8} for the
affine connection, so we are led to define a covariant derivative along the
curve \(x^\mu(\tau)\) by
\begin{equation}
  \Dworldline{A^\mu}
  \equiv
  \frac{\dd A^\mu}{\dd\tau}
  +
  \Gamma^\mu{}_{\nu\lambda}
  \frac{\dd x^\nu}{\dd\tau}A^\lambda.
  \tag{4.9.3}\label{eq:4.9.3}
\end{equation}
Equations \eqref{eq:4.5.8}, \eqref{eq:4.9.1}, and \eqref{eq:4.9.2} then
show that this is a vector:
\begin{equation}
  \Dworldline{A'^\mu}
  =
  \frac{\partial x'^\mu}{\partial x^\nu}
  \Dworldline{A^\nu}.
  \tag{4.9.4}\label{eq:4.9.4}
\end{equation}
The similarity between Eq.~\eqref{eq:4.9.3} and the formula
\eqref{eq:4.6.4} for the covariant derivative of a vector field is evident.

The same considerations lead us to define the covariant derivative along a
curve \(x^\mu(\tau)\) of a covariant vector \(B_\mu(\tau)\) by
\begin{equation}
  \Dworldline{B_\mu}
  \equiv
  \frac{\dd B_\mu}{\dd\tau}
  -
  \Gamma^\lambda{}_{\mu\nu}
  \frac{\dd x^\nu}{\dd\tau}B_\lambda,
  \tag{4.9.5}\label{eq:4.9.5}
\end{equation}
and with Eq.~\eqref{eq:4.5.2} we can easily show that this is a covariant
vector:
\begin{equation}
  \Dworldline{B'_\mu}
  =
  \frac{\partial x^\nu}{\partial x'^\mu}
  \Dworldline{B_\nu}.
  \tag{4.9.6}\label{eq:4.9.6}
\end{equation}
In the same way, the covariant derivative along a curve \(x^\mu(\tau)\) of a
general tensor \(T(\tau)\) is defined by adding to \(\dd T/\dd\tau\) a term
such as that in Eq.~\eqref{eq:4.9.3} for each upper index, and subtracting a
term such as that in Eq.~\eqref{eq:4.9.5} for each lower index. For instance,
\begin{equation}
  \Dworldline{T^\mu{}_\nu}
  \equiv
  \frac{\dd T^\mu{}_\nu}{\dd\tau}
  +
  \Gamma^\mu{}_{\lambda\rho}
  \frac{\dd x^\lambda}{\dd\tau}T^\rho{}_\nu
  -
  \Gamma^\rho{}_{\lambda\nu}
  \frac{\dd x^\lambda}{\dd\tau}T^\mu{}_\rho,
  \tag{4.9.7}\label{eq:4.9.7}
\end{equation}
and
\begin{equation}
  \Dworldline{T'^\mu{}_\nu}
  =
  \frac{\partial x'^\mu}{\partial x^\rho}
  \frac{\partial x^\sigma}{\partial x'^\nu}
  \Dworldline{T^\rho{}_\sigma}.
  \tag{4.9.8}\label{eq:4.9.8}
\end{equation}
The properties of covariant differentiation outlined in Sections
\ref{sec:4.6} through \ref{sec:4.8} can be easily extended to covariant
derivatives along a curve.

It should be mentioned that the covariant derivative of a tensor field along
a curve may be determined from its ordinary covariant derivative; for
instance, if \(T^\mu{}_\nu(x)\) is a tensor field, then
Eq.~\eqref{eq:4.9.7} gives
\begin{equation}
  \Dworldline{T^\mu{}_\nu}
  =
  \frac{\dd x^\lambda}{\dd\tau}\,
  \nabla_\lambda T^\mu{}_\nu.
  \tag{4.9.9}\label{eq:4.9.9}
\end{equation}
However, we shall see in Chapter~6 that tensors defined along curves cannot
always be promoted to tensor fields, and for these \(D/D\tau\) is the only
covariant derivative available.

It is often the case that a vector \(A^\mu(\tau)\) carried along a curve by a
particle does not change at \(\tau\) if viewed from a reference frame
\(\xi^\alpha_{x(\tau)}\) that is locally inertial at \(x(\tau)\). (This is
true for a particle's momentum and spin if it is subject to purely
gravitational forces; see Section~\ref{sec:5.1}.) In this frame the affine
connection as well as \(\dd A^\mu/\dd\tau\) vanishes, so
\begin{equation}
  \Dworldline{A^\mu}=0.
  \tag{4.9.10}\label{eq:4.9.10}
\end{equation}
This being a covariant statement, and true at \(x(\tau)\) in the locally
inertial system \(\xi^\alpha_{x(\tau)}\), it is therefore true in all
coordinate systems. The vector \(A^\mu\) is then subject to the first-order
differential equations
\begin{equation}
  \frac{\dd A^\mu}{\dd\tau}
  =
  -\Gamma^\mu{}_{\nu\lambda}
  \frac{\dd x^\nu}{\dd\tau}A^\lambda,
  \tag{4.9.11}\label{eq:4.9.11}
\end{equation}
that define \(A^\mu\) for all \(\tau\), given \(A^\mu\) at some initial
\(\tau\). A vector \(A^\mu(\tau)\) defined in this way along a curve
\(x^\mu(\tau)\) is said to be defined by \textit{parallel transport}. Any
tensor can be defined along a curve by parallel transport by requiring its
covariant derivative along the curve to vanish.
