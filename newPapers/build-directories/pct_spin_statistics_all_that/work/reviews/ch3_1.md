## Notation decisions and review items

The source's state vectors in (3-1) and (3-2), and the vacuum in the
definition, are set in Dirac notation as `\ket{\Psi_0}`. Source Hilbert-space
products in the discussion of tempered distributions and in (3-8) are set as
bras and kets. Source stars used for operator adjoints are rendered as
`^\dagger`; the adjoint field is consequently `\varphi^\dagger` and its test
function relation uses `\overline{g}`.

The source reads `P^\mu P_\mu=m^2` on printed page 97. The project house metric
is mostly plus, so the transcription uses `P^\mu P_\mu=-m^2` and retains the
source phrase “plus cone.” Under the same conversion, the support condition
`(x-y)^2\geq0` is represented as `(x-y)^2\leq0`, and the unsmeared locality
condition `(x-y)^2<0` is represented as `(x-y)^2>0`. The independent notation
audit checked these forms against the current native file.

The source writes spatial variables as `x` and `y` and the canonical delta as
`\delta(x-y)`. Explicit spatial arguments use bold `\mathbf{x}` and
`\mathbf{y}` in the native notation, while the delta remains unsuperscripted
to preserve the printed equation. The test-function space is the source's
script `\mathcal{S}`. No glyph remained unresolved after the high-resolution
inspection.

The dagger marks in the source are retained as explicit `\dagger`
superscripts in the two footnote units. The first reads “Defined in Section
2-6.” The second reads “This idea was introduced in Ref. 5.”
