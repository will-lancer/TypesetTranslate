## Review items

1. Figures 2-2, 2-3, and 2-4 currently have source-faithful captions and
   explicit native-reconstruction placeholders.  The final release must replace
   each placeholder with a native vector reconstruction or an approved source
   representation.
2. The source's two-component matrix calculation and cone inequalities use the
   printed mostly-minus sign convention, in particular the statement that a
   space-like real vector has squared norm `< 0`.  The project-wide Weinberg
   guide specifies the mostly-plus metric.  A notation-map decision is needed
   before strict release: either record this 2-by-2 formalism as a local source
   convention or convert the cone signs, scalar-product display, and related
   inequalities together.
3. The source has no usable OCR text layer for this packet.  Equation symbols,
   accents, and punctuation were checked against the rendered page images.  The
   source uses a bar for the complex conjugate of a matrix or component in the
   2-by-2 calculation; the native file uses the house-style `*` for ordinary
   complex conjugation where the same operation is unambiguous.
4. The first display on printed page 63, the $(-1)^{j+k}$ display on page 64,
   and the intermediate displays on pages 65--68 are intentionally unnumbered;
   only the printed equations (2-84)--(2-93) carry tags.
