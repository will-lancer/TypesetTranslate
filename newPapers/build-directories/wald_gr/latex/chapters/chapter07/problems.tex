\chapterproblems

\begin{enumerate}[label=\arabic*.,leftmargin=*]
\item Prove that \(\mathcal L_\psi\omega_a=0\) (see
equation~\eqref{eq:7.1.10}) directly, without appealing to the arguments given in
the text, i.e., prove first that \(\mathcal L_\psi\epsilon_{abcd}=0\), and then use
only \(\mathcal L_\psi\xi^a=0\) and the formulas of appendix C.

\item Derive Einstein's equations~\eqref{eq:7.1.24}--\eqref{eq:7.1.27} for the
metric~\eqref{eq:7.1.22}.

\item For a stationary, axisymmetric metric of the form~\eqref{eq:7.1.17}, we
define the \emph{locally nonrotating observers} to be the family of observers which
are “at rest” with respect to the \(t=\text{constant}\) hypersurfaces, i.e., whose
4-velocity, \(u^a\), is proportional to \(\nabla^at\).
\begin{enumerate}[label=\alph*),leftmargin=2.5em]
\item Show that the angular momentum, \(L\), of such observers vanishes, where
\(L\) is defined by \(L=u^a\psi_a\) (see equation~\eqref{eq:6.3.13}).

\par\medskip

\item Show that such observers rotate with coordinate angular velocity
\(d\phi/dt=-W/X\). Since, in general, the metric~\eqref{eq:7.1.17} represents
the exterior field of a stationary, axisymmetric rotating body (or black hole), we
may interpret this \(d\phi/dt\) as resulting from the “dragging of inertial frames”
produced by rotating matter, in accord with Mach's principle.
\end{enumerate}

\item Since any isometry \(\psi\) leaves the Weyl tensor invariant,
\(\psi^*C_{abcd}=C_{abcd}\), it follows that if \(k^a\) is a principal null
vector, then so is \(\psi^*k^a\). Since there exists only a discrete set of principal
null vectors at each point, it follows that if \(\psi_t\) is a smooth one-parameter
group of isometries which leaves \(p\in M\) fixed, then \(\psi_t^*\) must leave
invariant all principal directions at \(p\). Use this fact to prove the following
results (without resorting to a calculation of \(C_{abcd}\) and its principal null
directions):
\begin{enumerate}[label=\alph*),leftmargin=2.5em]
\item Every spherically symmetric spacetime is algebraically special. Furthermore,
every static, spherically symmetric spacetime, equation~\eqref{eq:6.1.5}, is of
algebraic type II--II.

\par\medskip

\item Every Robertson--Walker spacetime, equation~\eqref{eq:5.1.11}, is
conformally flat, \(C_{abcd}=0\).
\end{enumerate}

\item Derive equation~\eqref{eq:7.4.8}.
\end{enumerate}
