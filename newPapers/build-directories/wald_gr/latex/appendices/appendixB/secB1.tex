\subsection{Differential Forms}\label{sec:B.1}

Let \(M\) be an \(n\)-dimensional manifold. A differential \(p\)-form is a totally
antisymmetric tensor of type \((0,p)\), i.e., \(\omega_{a_1\ldots a_p}\) is a \(p\)-form
if
\begin{equation}
  \omega_{a_1\ldots a_p}=\omega_{[a_1\ldots a_p]}.
  \tag{B.1.1}\label{eq:B.1.1}
\end{equation}
We denote the vector space of \(p\)-forms at a point \(x\) by
\(\Lambda^pT_x^\vee M\) and the collection of \(p\)-form fields by
\(\Omega^p(M)=\Gamma\!\left(\Lambda^pT^\vee M\right)\). Note that
\(\Lambda^pT_x^\vee M=\{0\}\) if \(p>n\) and
\(\dim\Lambda^pT_x^\vee M=n!/p!(n-p)!\) for \(0\leq p\leq n\). If we take the outer
product of a \(p\)-form \(\omega_{a_1\ldots a_p}\) and a \(q\)-form
\(\mu_{b_1\ldots b_q}\), we will get a tensor of type \((0,p+q)\); but since this
tensor will not, in general, be totally antisymmetric, it is not a \((p+q)\)-form.
However, we can totally antisymmetrize this tensor, thus producing a map
\[
  \wedge:\Lambda^pT_x^\vee M\times\Lambda^qT_x^\vee M
  \longrightarrow\Lambda^{p+q}T_x^\vee M
\]
via
\begin{equation}
  (\boldsymbol\omega\wedge\boldsymbol\mu)_{a_1\ldots a_pb_1\ldots b_q}
  =\frac{(p+q)!}{p!q!}\,
  \omega_{[a_1\ldots a_p}\mu_{b_1\ldots b_q]}.
  \tag{B.1.2}\label{eq:B.1.2}
\end{equation}
(If \(p+q>n\), this tensor, of course, will be zero.) We define the vector space of
all differential forms at \(x\) to be the direct sum of the
\(\Lambda^pT_x^\vee M\),
\begin{equation}
  \Lambda T_x^\vee M=\bigoplus_{p=0}^{n}\Lambda^pT_x^\vee M.
  \tag{B.1.3}\label{eq:B.1.3}
\end{equation}
The map
\(\wedge:\Lambda T_x^\vee M\times\Lambda T_x^\vee M\longrightarrow\Lambda T_x^\vee M\)
gives \(\Lambda T_x^\vee M\) the structure of a Grassmann algebra\footnote{See, e.g.,
Bishop and Crittenden (1964) for the definition of a Grassmann algebra.} over the
vector space of one-forms.

If we are given a derivative operator, \(\nabla_a\), we could define a map from smooth
\(p\)-form fields to \((p+1)\)-form fields by
\begin{equation}
  \omega_{a_1\ldots a_p}\longmapsto
  (p+1)\nabla_{[b}\omega_{a_1\ldots a_p]}.
  \tag{B.1.4}\label{eq:B.1.4}
\end{equation}
If instead we were given another derivative operator \(\widetilde\nabla_a\), we would
obtain the map
\begin{equation}
  \omega_{a_1\ldots a_p}\longmapsto
  (p+1)\widetilde\nabla_{[b}\omega_{a_1\ldots a_p]}.
  \tag{B.1.5}\label{eq:B.1.5}
\end{equation}
However, according to Eq.~\eqref{eq:3.1.14}, we have
\begin{equation}
  \nabla_{[b}\omega_{a_1\ldots a_p]}
  -\widetilde\nabla_{[b}\omega_{a_1\ldots a_p]}
  =\sum_{j=1}^{p}C^d_{[ba_j}
  \omega_{a_1\ldots\lvert \dd\rvert\ldots a_p]}=0
  \tag{B.1.6}\label{eq:B.1.6}
\end{equation}
since \(C^c{}_{ab}\) is symmetric in \(a\) and \(b\). Thus the map defined by
Eq.~\eqref{eq:B.1.4} is independent of derivative operator, i.e., it is well defined
without the presence of a preferred derivative operator on \(M\). We denote this map
by \(d\). In particular, we may use the ordinary derivative, \(\partial_a\), associated
with any coordinate system to calculate \(d\).

Since the index structure of differential forms is trivial, it is customary to drop the
indices when writing them; e.g., we write \(\boldsymbol\omega\) instead of
\(\omega_{a_1\ldots a_p}\) and write \(\boldsymbol\omega\wedge\boldsymbol\mu\)
instead of \((\boldsymbol\omega\wedge\boldsymbol\mu)_{a_1\ldots b_q}\). (The only
disadvantage in doing so is that we must remember the dimensionality of the forms
with which we are dealing.) We shall use boldface letters for forms to avoid
confusion with functions. We denote the \((p+1)\)-form resulting from the action of
the map \(d:\Omega^p(M)\to\Omega^{p+1}(M)\) on the \(p\)-form
\(\boldsymbol\omega\) by \(\dd\boldsymbol\omega\).

An important property of the map \(d\) is that \(\dd^2=\dd\circ d=0\). This result,
known as the \emph{Poincar\'e lemma}, follows from the fact that we can compute \(d\)
using an ordinary derivative operator. Indeed, restoring the indices, we have for an
arbitrary smooth \(p\)-form \(\boldsymbol\omega\),
\begin{equation}
  (\dd^2\boldsymbol\omega)_{bca_1\ldots a_p}
  =(p+2)(p+1)\partial_{[b}\partial_c\omega_{a_1\ldots a_p]}=0,
  \tag{B.1.7}\label{eq:B.1.7}
\end{equation}
because of the equality of mixed partial derivatives in \(\mathbb R^n\).

Conversely, it can be shown (see, e.g., Flanders 1963) that if one has a closed
\(p\)-form, i.e., a \(p\)-form \(\boldsymbol\alpha\) satisfying
\(\dd\boldsymbol\alpha=0\), then locally (i.e., in any open region diffeomorphic to
\(\mathbb R^n\)) this form is exact, i.e., there exists a \((p-1)\)-form
\(\boldsymbol\beta\) such that \(\boldsymbol\alpha=\dd\boldsymbol\beta\). However, in
general this result is not valid globally. Indeed, an important theorem in algebraic
topology due to de Rham establishes that the dimension of the vector space of closed
\(p\)-forms modulo the exact \(p\)-forms equals a topological quantity: the \(p\)th
Betti number of the manifold.\footnote{Roughly speaking, the \(p\)th Betti number of
\(M\) is the number of independent \(p\)-dimensional boundaryless surfaces in \(M\)
which are not themselves boundaries of \((p+1)\)-dimensional regions. For more
details, including a complete statement and proof of de Rham's theorem, see, e.g.,
Warner (1971).}
