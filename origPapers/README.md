# Original sources

[Repository](../README.md) · [Book catalogue](../newPapers/README.md)

This directory stores original book scans and reference images. Project
source maps and manifests identify the files they use, including sources
stored within individual build workspaces.

Keep source filenames and bytes stable so provenance checks continue to
resolve. Put edited LaTeX in the relevant build workspace and exported editions
in the book's folder under `newPapers/`.
